## Deprecations

None. Nothing in the current surface is deprecated.

## Bumping the floor

1. Choose the level being dropped; it must be below the current level.
2. Raise `APP_API_FLOOR` and the `floor` in `modules/Astral/AppKit/AppApi.qml` together — `daemon/tests/test_appkit_constants.rs` fails otherwise.
3. Remove only members whose `removal` level is at or below the new floor.
4. Run `astral-plasma app api --write`, then `make test`: the surface snapshot must change in the same commit.
5. Note the floor bump in `docs/UPDATES.md` so users learn why an old app stopped loading.

## Releasing an app

1. Bump `version` in `manifest.json` (semver; a permission change is at least minor).
2. Add a changelog entry naming user-visible changes.
3. `astral-plasma app lint` and `astral-plasma app test` must pass.
4. `astral-plasma app pack` and add the artifact plus its digest to the catalog.
5. If `kernelApi` changed, the app is rebuilt against that level and the catalog entry says so.
